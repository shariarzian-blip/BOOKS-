### Editing लौकिक · अलौकिक

All text lives in `documentaries/laukik-alaukik/content.mjs`. After editing it, run `node build.mjs` in that folder to regenerate `index.html` and the `.md` files. The images in `art/` are previews of the Magnific generations; `node posters.cjs` (needs Playwright) lays the Hindi titles over them and writes `posters/`.
